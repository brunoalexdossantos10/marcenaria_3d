Photo-derived diffuse textures, sampled from the original 2K maps. The standard files are 512 px; `-high` files are 1024 px. They retain grain and subtle color variation while allowing the configurator to tint each material. All are WebP, and only the selected resolution is fetched. Original assets are CC0 from Poly Haven:

- `oak*.webp`: [Oak Veneer 01](https://polyhaven.com/a/oak_veneer_01), Jenelle van Heerden.
- `oak-light*.webp`: [Oak Veneer 03](https://polyhaven.com/a/oak_veneer_03), Jenelle van Heerden.
- `cabinet-wood*.webp`: [Wood Table 001](https://polyhaven.com/a/wood_table_001), Dimitrios Savva and Rico Cilliers. Used as a visual approximation for Freijó; it is not a manufacturer's Freijó pattern.
- `walnut*.webp`: [Walnut Veneer](https://polyhaven.com/a/walnut_veneer), Jenelle van Heerden.
- `timber*.webp`: [Oak Veneer 05](https://polyhaven.com/a/oak_veneer_05), Jenelle van Heerden. Generic amadeirado option.
- `dark-wood*.webp`: [Natural Walnut Veneer](https://polyhaven.com/a/natural_walnut_veneer), Jenelle van Heerden. Generic dark wood option.
- `wood-floor*.webp`: [Wood Floor](https://polyhaven.com/a/wood_floor), Dimitrios Savva.
- `marble*.webp`: [Marble 01](https://polyhaven.com/a/marble_01), Rob Tuytel.

The small normal and roughness maps are derived from the matching Poly Haven PBR maps. Actual MDF decor and exact colors depend on the manufacturer's selected SKU and a physical sample.
